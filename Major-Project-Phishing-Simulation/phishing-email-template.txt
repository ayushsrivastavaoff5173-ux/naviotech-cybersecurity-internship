NOTES FOR SIMULATION ADMINISTRATOR:

1. This email uses common phishing tactics:
   - Urgency ("24 hours")
   - Authority impersonation ("IT Support")
   - Legitimate-looking sender domain (spoofed, but recognizable in test environment)
   - Clear call-to-action (link + manual entry option)

2. The "verification" form is a Google Form styled to look like a login page
   (see: google-forms-setup-guide.txt)

3. ALL participants should have signed consent forms BEFORE this email is sent.

4. The email footer message is OPTIONAL — use only if you want immediate 
   feedback during the simulation. Some programs prefer to reveal after 7-10 days
   for more authentic behavior measurement.

5. If using a real email domain (not spoofed test domain), ensure:
   - IT Security has approved the simulation
   - Email headers clearly show it's a test (add X-Test header, etc.)
   - SPF/DKIM/DMARC records don't trigger false positives in email gateways

6. Track metrics:
   - Send timestamp
   - Open timestamp (via web beacon or form access logs)
   - Click timestamp
   - Form submission data (username/password attempts)
   - Any user reports to IT

7. After simulation period (recommend 7 days):
   - Send all-clear message revealing the test
   - Provide training resources to anyone who fell for it
   - Aggregate results anonymously
   - Conduct follow-up training 1-2 weeks later
