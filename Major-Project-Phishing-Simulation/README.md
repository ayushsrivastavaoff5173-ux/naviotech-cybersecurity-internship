# Major Project: Phishing Awareness Simulation Using Social Engineering Techniques

## Overview

This project demonstrates a phishing awareness simulation in a controlled and ethical environment for cybersecurity education.

## Project Files

- Major_Project_Report.docx
- Major_Project_Presentation.pptx
- phishing-email-template.txt
- google-forms-setup-guide.txt
- consent-form-template.txt
- testing-execution-guide.txt

## Topics Covered

- Phishing attacks
- Social Engineering
- User Awareness
- Ethical Simulation
- Security Awareness Training
- Risk Analysis

## Ethical Notice

This project is intended **only for educational purposes** and should be conducted with informed consent from participants. Do not use these materials for unauthorized or deceptive activities.

## How to Use

1. Read the project report.
2. Review the presentation.
3. Follow the setup guide.
4. Use the email template only in an authorized training environment.
5. Document observations and lessons learned.
