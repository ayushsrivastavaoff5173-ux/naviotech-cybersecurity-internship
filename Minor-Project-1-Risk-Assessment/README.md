# Minor Project 1: Cybersecurity Risk Assessment Framework for SMEs

## Overview
This project develops a structured, repeatable risk assessment model for small and medium enterprises (SMEs), aligned with the NIST Cybersecurity Framework.

## Deliverables
- **Minor_Project_1_Report.docx** — Full 6-page report covering:
  - Introduction & objectives
  - NIST CSF methodology
  - Risk assessment model (Likelihood × Impact scoring)
  - Risk evaluation metric (High/Medium/Low)
  - 10 identified SME risks with mitigation strategies
  - 3 case study validations
  - Findings & best practices
  - Conclusion

- **Risk_Assessment_Matrix.xlsx** — Interactive spreadsheet:
  - 10-risk assessment matrix with live formulas
  - Risk scores auto-calculate (Likelihood × Impact)
  - Color-coded by risk level
  - Summary dashboard with aggregate statistics

- **Minor_Project_1_Presentation.pptx** — 10-slide summary:
  - Project overview, objectives, methodology
  - NIST CSF framework explanation
  - Risk evaluation metric (3-level system)
  - Risk matrix snapshot
  - Mitigation strategies by control type
  - Case studies & key findings
  - Conclusion & recommendations

## Key Findings
- **4 High-Risk items identified** (Risk score 15-25):
  - Phishing emails (Score: 20)
  - Ransomware (Score: 20)
  - Unpatched software (Score: 16)
  - Weak passwords (Score: 15)

- **Most cost-effective mitigation:** Security awareness training (addresses human-factor risks)
- **Least costly MFA + strong patch management** reduce risk exposure significantly

## How to Use
1. Open `Risk_Assessment_Matrix.xlsx` in Excel/LibreOffice
2. Review the risk matrix (10 identified SME threats)
3. Adjust Likelihood/Impact ratings if needed (scores recalculate automatically)
4. Use the Summary sheet to track high-risk items
5. Refer to the report for detailed mitigation strategies per risk

## Technologies & Tools
- Microsoft Excel (risk matrix calculations)
- NIST Cybersecurity Framework (methodology reference)
- Risk scoring model: Quantitative (Likelihood × Impact)
